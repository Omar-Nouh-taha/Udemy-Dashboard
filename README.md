# 🎓 Udemy Courses Analysis Dashboard

## 📌 Project Overview

This project is an interactive **Power BI dashboard** designed to analyze Udemy online courses and uncover insights related to **courses, subscribers, reviews, pricing, subjects, levels, and payment types**.

The dashboard transforms course data into interactive visualizations that help understand course popularity, pricing patterns, and the relationship between course price and subscriber engagement.

---

## 🎯 Project Objectives

The dashboard was developed to answer key business questions such as:

1. How many courses are available?
2. How many subscribers and reviews are there?
3. Which subjects have the highest number of subscribers?
4. How are courses distributed across different levels?
5. How has the number of courses changed over the years?
6. Which courses have the highest number of subscribers?
7. What are the minimum, maximum, and average course prices?
8. How does course price relate to the number of subscribers?
9. How are subscribers distributed across different price categories?
10. Which payment methods are most commonly used?

---

## 📊 Dashboard Pages

### 1. Overview

The Overview page provides a high-level summary of the Udemy course dataset.

**KPIs include:**

* Total Courses
* Total Reviews
* Total Subscribers
* Total Lectures
* Maximum Course Price
* Minimum Course Price
* Average Course Price

**Visualizations include:**

* Subscribers by Subject
* Course Distribution by Subject and Level
* Courses Published by Year
* Top Courses by Subscribers

---

### 2. Price Analysis

The Price Analysis page focuses on pricing and its relationship with subscriber engagement.

**Analysis includes:**

* Average Price by Subject
* Course Price vs. Subscribers
* Subscribers by Price Category
* Subscribers by Payment Type
* Price distribution analysis

These visualizations help identify how pricing varies across subjects and how course pricing is associated with subscriber activity.

---

### 3. Details

The Details page provides a more detailed view of individual course information.

Users can interact with the dashboard using filters and explore course-level data.
